# covertwo

A small, modest NFL live scoreboard. One compact row per game, grouped by
day, with a Europe/US time toggle.

**Live:** https://moudlajs.github.io/covertwo/

## Development

```sh
npm ci
npm run dev
```

See [CONTRIBUTING.md](CONTRIBUTING.md) for the workflow and checks, and the
[milestones](https://github.com/moudlajs/covertwo/milestones) for the roadmap.
